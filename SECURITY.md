# Security Policy

Privates Forschungs-Repo (Coworker Research / Coworkerz). Verwundbarkeiten oder
Integritaets-Probleme (z.B. SOURCES.md-Abweichungen, manipulierte Evidenz-Logs)
bitte direkt als GitHub-Issue mit Label `security` melden - kein oeffentlicher
Disclosure-Prozess noetig, solange das Repo privat ist.

Supply-Chain-Haertung: Actions sind SHA-gepinnt, zizmor auditiert Workflows,
Dependabot mit 7-Tage-Cooldown.
