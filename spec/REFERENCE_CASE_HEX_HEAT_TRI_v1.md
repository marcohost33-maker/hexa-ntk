## 1. Purpose

One canonical hex-PDE case whose continuous AND semi-discrete solutions are
known in closed form, so the repository's hex operator can be verified against
an exact oracle before any learning backend is compared with it (#60: "No
learning-backend claim before Phase 0 is green").

Phase 0a covers this case only. The MMS case (variable coefficient + source)
and the periodic hex torus (second BC family) are Phase 0b and are NOT part of
this contract; see `spec/REFERENCE_CASES_HEX_PHASE0B_v1.md`.

## 2. Problem

- Domain: the equilateral triangle `T` with vertices `(0, 0)`, `(1, 0)`,
  `(1/2, sqrt(3)/2)` (side 1).
- Equation: `u_t = kappa * Lap(u)` in `T`, `kappa > 0`.
- Boundary: homogeneous Dirichlet, `u = 0` on the boundary of `T`.
- Initial data: a finite sum of Lamé modes, `u0 = sum_i a_i * phi_i`.
- Exact solution: `u(x, t) = sum_i a_i * exp(-kappa * lambda_i * t) * phi_i(x)`.

Default study data (section 5): `kappa = 1`, `T_final = 0.01`, modes
`(1, 1, sin)` with `a = 1`, `(1, 2, sin)` with `a = 1/2`, `(1, 2, cos)` with
`a = 1/4`.

## 3. Discretisation under test

- Lattice: `h = 1/N` (`N >= 3`), nodes `x_ij = h * (i + j/2, j * sqrt(3)/2)`.
  Nodes with `i, j >= 1` and `i + j <= N - 1` are the unknowns.
  Nodes with `i = 0`, `j = 0` or `i + j = N` lie on the edges of `T`.
- Neighbour slots, counter-clockwise from east, in index offsets `(di, dj)`:
  E `(1, 0)`, NE `(0, 1)`, NW `(-1, 1)`, W `(-1, 0)`, SW `(0, -1)`, SE `(1, -1)`.
- Slot value `-1` means **homogeneous Dirichlet boundary node (value 0)**. It
  does NOT mean "no neighbour". The H1 proxy in `benchmark_hex_v3` drops `-1`
  slots; this operator counts them as `0 - u_i`.
- Operator: `(L_h u)_i = w * sum_{s=1..6} (u_{n(i,s)} - u_i)`, with
  `u_{-1} = 0` and `w = hex_laplacian_stencil_weight(h) = 2/(3 h^2)` taken from
  the engine `src/hexantk_v3.py`. That engine function is the code under
  verification.

## 4. Exact discrete eigenvectors (why this case is an oracle)

Let `G` be the dihedral group of order 6 generated by the reflections across
the lines through the origin at 0 and 60 degrees. With `p = m + n` and `q = n`,
for integers `m, n >= 1`:

    k_{m,n}    = 2*pi * (2p/3 - q/3, q/sqrt(3))
    phi^sin    = sum_{g in G} det(g) * sin(<g k, x>)
    phi^cos    = sum_{g in G} det(g) * cos(<g k, x>)
    lambda     = |k|^2 = (16 pi^2 / 9) * (m^2 + m n + n^2)
    lambda_h   = (8 / (3 h^2)) * sum_{a in {0, 60, 120 deg}} sin^2(h <k, a> / 2)
               = lambda - h^2 lambda^2 / 16 + O(h^4)

- `phi^cos` vanishes identically when `m = n`, because `k` is then normal to a
  mirror line. A mode that vanishes on the lattice is rejected.
- Exactness:
  - `G` maps the six lattice directions onto themselves, so every plane wave
    `<g k, x>` has the same lattice symbol `-lambda_h`.
  - The antisymmetrisation makes each mode vanish on the three edges. The
    third edge is handled by a lattice translation, which exists because
    `k` lies in 2*pi times the dual of the reflection translation lattice.
  - Hence `L_h phi = -lambda_h phi` holds exactly on the interior nodes, for
    every `N`.
- Consequence: the semi-discrete solution is
  `u_h(t) = sum_i a_i * exp(-kappa * lambda_h,i * t) * phi_i`. It is exact in
  time, so the only error is the spatial error in `lambda_h`.
- The leading error term is isotropic and has a known coefficient, which the
  study checks (section 5).

The fundamental mode `(1, 1, sin)` equals `-2 * [sin(4 pi y/sqrt3) -
sin(2 pi (x + y/sqrt3)) + sin(2 pi (x - y/sqrt3))]`, the form used in #60, and
has one sign in the interior.

## 5. Verification protocol and gate

Levels `N = 16, 32, 64, 128` (refinement ratio `r = 2`). Other configurations need at
least four levels with one constant ratio `r > 1.3` (Celik et al. 2008).

**Recorded per level:**
- `h` and the number of nodes;
- the eigen-residual of every mode;
- the Rayleigh quotient `lambda_RQ = -(phi . L_h phi)/(phi . phi)` of the
  fundamental mode, computed from the assembled operator;
- the closed-form `lambda_h` and the coefficient ratio
  `(lambda - lambda_RQ) / (h^2 lambda^2 / 16)`;
- the relative L2 and max-norm errors of `u_h(T_final)` against `u(T_final)`
  at the nodes. All cells have the same area, so the area weights cancel.

**Code verification** (all must hold):

1. Eigen-residual `max |L_h phi + lambda_h phi| / (lambda_h * max |phi|) <= 1e-10`
   for every mode and every level.
2. `|lambda_RQ - lambda_h| <= 1e-10 * lambda_h` for every level.
3. The coefficient ratio of every mode at the finest level is in `[0.99, 1.01]`.
4. The observed order of the heat-solution error against the exact solution,
   `p = log2(e_N / e_2N)`, is in `[1.95, 2.05]` for both pairs among the three
   finest levels.

**Solution verification:**
- Quantity of interest: `lambda_RQ` of the fundamental mode.
- Method: Celik et al. 2008, with constant `r`. The three finest levels give
  `p = |ln|eps32/eps21|| / ln r`, `e_a21 = |(f1 - f2)/f1|` and
  `GCI_fine = 1.25 * e_a21 / (r^p - 1)`. Here `f1` is the finest level.

5. `p` is in `[1.95, 2.05]` (decision #60).
6. `eps32/eps21 > 0`, i.e. the convergence is monotone, not oscillatory.
7. Asymptotic range: `|p(16,32,64) - p(32,64,128)| <= 0.05`. This uses four
   levels. Roache's single-triplet ratio `GCI_32 / (r^p GCI_21)` equals
   `f1/f2` by construction for constant `r`, so it carries no information and
   is not used.
8. `GCI_fine` is finite and `>= 0`. It is reported as the numerical
   uncertainty, a relative fraction.
9. `GCI_fine >= |lambda - lambda_RQ(finest)| / lambda`. The exact value is
   known in this oracle case, so the uncertainty estimate must cover the true
   error of the finest level.

The study passes only if criteria 1-9 all hold. The oracle script exits
non-zero otherwise.

## 7. Positivity gate on the assembled operator (issue #60, item 1)

The explicit step `u + dt * kappa * L_h u` maps every non-negative state to a
non-negative state if the assembled operator has non-negative off-diagonals and
`dt <= min_i 1 / (kappa * |L_ii|)`. Both conditions are also necessary: a
negative off-diagonal entry, or a larger `dt`, lets a single positive node value
produce a negative value. The gate additionally requires a negative diagonal
(a dissipative operator, `-L_h` an M-matrix), which makes the bound finite.

On this lattice the bound equals `hex_positivity_max_dt(h, kappa) = h^2/(4 kappa)`.

The gate reads the sign structure from the assembled operator and raises
`ValueError` (contract error) on a violation or on a larger `dt`.

It secures positivity only for this linear scheme. It is not a discrete maximum
principle for other operators. Linear MPFA is not monotone (Lipnikov et al.,
JCP 228 (2009) 703; see #60).

## 8. Claim boundary

This case verifies:
- the regular hex Laplacian weight;
- the lattice and Dirichlet assembly;
- the second-order convergence of the semi-discrete solution;

all for one smooth, linear, isotropic problem.

It does not:
- validate physics;
- verify irregular or anisotropic grids, variable coefficients, or other
  boundary conditions;
- assess any neural operator;
- turn any number into "ground truth" outside the context of use above.
